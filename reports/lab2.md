## 问答
1. SV39 页表页表项由保留位、物理页号、RSW、标志位构成。标志位如下：
    + V(Valid)：该页表项是否有效
    + R(Read)/W(Write)/X(eXecute)：分别控制索引到这个页表项的对应虚拟页面是否允许读/写/执行；
    + U(User)：控制索引到这个页表项的对应虚拟页面是否在 CPU 处于 U 特权级的情况下是否被允许访问；
    + G(Global)：全局位。
    + A(Accessed)：处理器记录自从页表项上的这一位被清零之后，页表项的对应虚拟页面是否被访问过；
    + D(Dirty)：处理器记录自从页表项上的这一位被清零之后，页表项的对应虚拟页面是否被修改过。
2. +    * Instruction page fault, Load page fault, Store/AMO page fault
        * scause: 12, 13, 15（与上面对应）
        * stval: 导致异常的虚拟地址的值；
        * spec: 产生异常的程序计数器的值
    + 好处：减少反复 IO 带来的时间损耗。
    +   * 大小估计：10GB 大约为 2.5M 页，一页对应一个 PTE 为 8B，总计   20MB左右。注意到多级页表产生的额外占用可以忽略不计。
        * 维护一个队列。每次触发 lazy 操作，就把对应的操作压入队列。如果触发了缺页的错误，就把依次进行队列中的操作，清空队列后再处理相关错误。
    + 页表项中的 V 置为0
3.  + 由于单页表的设计无需在用户态和内核态之前切换页表，所以页表切换只会发生在进程切换。此时切换方法同双页表设计，使用 satp 寄存器处理。
    + 使用 PTE 中的标志位 U。内核地址中 U 置为0，其他置为 1。
    + 减少了切换页表的次数，维护起来更简单。
    + 特权级切换和进程切换时需要更换页表。
    + 实现单页表的操作系统，会在进程切换时更换页表。
